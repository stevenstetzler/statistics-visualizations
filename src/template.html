Data, model, residuals

Step-by-step tutorial →

Three observations are one point in \(\mathbb R^3\). A line \(y = a + b\,x\) can only reach a 2-D plane of that space. Fitting drops a perpendicular; what is left lives in the remaining \(n - p = 1\) direction.

The usual picture

Drag a point up/down. least-squares line, your \((a, b)\) line. Shading: the blue band holds every line whose \((a, b)\) is inside the 95% parameter ellipse for the current \(\sigma\); the violet band is \(\pm\sigma\) of noise around your line.

Where χ² comes from

Treat \(\mathbf c\) as the true model and add Gaussian noise \(\boldsymbol\varepsilon \sim \mathcal N(0, \sigma^2 I)\). Each dot in 3-D is a possible dataset \(\mathbf y = \mathbf c + \boldsymbol\varepsilon\).

Data noise

Bars: 4000 simulated datasets from the cloud chosen above. Curve: \(\chi^2\) density. For the data-driven clouds the scale is \(\hat\sigma^2 = \mathrm{RSS}/(n-p)\), so there is no marker. marker: your current y.
